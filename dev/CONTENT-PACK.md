## A. 通用：权威引用（所有页面统一用这些名称与日期）
按效力层级（高→低）：
1. **《中华人民共和国农村集体经济组织法》** — 2024-06-28 通过，**2025-05-01 施行**。要点：集体经济组织为“特别法人”；第36条 八类集体财产不得分割到个人；第40–42条 收益按章程提取公积公益金后分配；**第44条 集体资金不得存入个人账户**；第45–46条 定期财务公开、年度报告与分配方案应在成员大会前10日提供查阅；第26–27条 成员大会需 2/3 以上成员参加、2/3 以上同意；第32条 监事会监督。
2. **《农村集体经济组织财务制度》**（财政部、农业农村部，2022）。要点：成员大会—理事会—监事会—会计 四层管理；**严禁公款私存、私设小金库、“白条”抵库、坐收坐支**；收益分配顺序：弥补亏损→提取公积公益金→成员分配；非生产性开支限额管理、纳入预算。
3. **《农村集体经济组织会计制度》**（财会〔2023〕14号，**2024-01-01 施行**）：村会计记账的直接依据。
4. **《农村集体经济组织财务公开规定》**（农业部、监察部）：一般财务每月公开、重大事项及时公开；公开前由民主理财小组/监事会（3–5人）审核签字、报乡镇农经部门备案；**公开栏张贴一般不少于 7 天**。
5. **《关于稳步推进农村集体产权制度改革的意见》**（2016）、**九部门清产核资通知**（2017）：资产按 资源性 / 经营性 / 非经营性 三类登记建账。
6. **各地《农村产权流转交易管理办法》**：集体资产资源交易、工程招投标“**应进必进**”，进农村产权交易平台公开进行，严禁场外私下交易。
7. **本县（市、区）三资管理实施细则**（示例标注“湖南·中方县 2025”）：阈值/权限/时限的本地化依据，**以本县市最新制度为准**。
8. **2025 年中央一号文件**：持续深化农村集体资金资产资源管理专项治理，阳光透明。

- 红线：坐收坐支、白条抵库、公款私存、私设小金库、违规出借资金、资产低价处置、违规发包、虚报冒领、超标准开支、挪用集体资金、合同显失公平。（共 10 类违纪手法）

## C. 关键流程（步骤卡用）
- **报销七步签字链**：①经办人取得合法票据并注明用途、签字 → ②出纳审核整理 → ③监事会/民主理财小组审查签字盖章 → ④法定代表人“一支笔”审批 → ⑤乡镇代理中心审核 → ⑥会计审核记账 → ⑦归档。配套：单笔 > 1000 元须银行结算、资金直达供应商；现金收入 3 日内存入专户。
- **票据“六有”自检**：有真实事由、有合法正式票据、有经办人签字、有验收/证明人、有审批人签字、有相关附件（合同/会议记录等）。
- **银农直联六步三岗**：报账员平台扫描上传凭证 → 一级审核人（乡镇经管站）→ 二级审核人（代理中心）→ 系统直连银行付款 → 自动生成电子凭证 → 月初打印上月明细交会计入账。三岗：申请人 / 一级审核 / 二级审核，**申请人与审核人不得同一人**；各环节 **2 个工作日**内审核，不合规凭证驳回；原则上禁现金、村务卡严禁化整为零拆分。
- **四议两公开六步**：①党组织提议 → ②村两委（理事会）商议 → ③党员大会审议 → ④成员（代表）大会决议（**2/3 出席、半数以上通过**，无记名/举手）→ ⑤决议公开 → ⑥实施结果公开。适用：资产处置、资源发包、工程项目、重大举债、收益分配等。
- **清产核资九步**：清查 → 登记 → 核实 → 公示 → 确认 → 建台账 → 审核备案 → 汇总上报 → 纳入全国监管平台。
- **资源台账六步**：分类（土地/林地/草地/荒地/滩涂）→ 逐项登记（名称/类别/坐落/面积）→ 关联合同 → 录入平台 → 动态更新 → 定期清理。
- **资产盘点账实不符**：盘盈按市价入账；盘亏按金额分级核销、查明原因。
- **成员身份三要件 + 三榜公示**：户籍在/曾在本集体 + 稳定权利义务关系 + 以集体土地等为基本生活保障；三榜公示每榜 **≥ 5 天** + 成员大会表决。

## D. 关键阈值（阈值速查页 + 速查结果卡，全部标“以本县市最新制度为准”，示例取中方县2025）
| 事项 | 档位 | 须走的程序 |
|---|---|---|
| 资产购建 | ≤5000元 | 理事会+监事会共同决定 |
| 资产购建 | 5000元–5万元 | 成员代表大会讨论通过 + 乡镇登记备案 |
| 资产购建 | >5万元 | 成员大会讨论 + 公示 + 乡镇审核备案 |
| 资产处置 | ≤5000元 | 理事会提方案 + 成员大会通过 + 公示 |
| 资产处置 | >5000元 | 四议两公开 + 公开拍卖/进场 + 乡镇备案 |
| 工程建设 | <4万元 | 成员大会通过后实施 |
| 工程建设 | 4万–100万元 | 四议两公开 + 简易公开招标 + 乡镇备案（先备案后招标）|
| 工程建设 | >100万元 | 按《招标投标法》执行 |
| 现金/资金 | 单笔>1000元 | 须银行结算、资金直达供应商；收款3日内存入专户 |
| 进场交易 | 资源类/资产类/采购达地方门槛 | “应进必进”农村产权交易平台（如非资源类资产1万、资源类土地2000、采购5万以上，地区不同）|

## E. 典型问答（qa-chat / search / 悬浮助手 示例）
1. **招待餐费能不能报？** 结论：不能直接报；非生产性开支须限额、纳入预算、严禁违规吃喝；确属公务且在限额内才可按审批流程入账。依据：财务制度·非生产性开支。
2. **集体的地能不能换 / 怎么发包？** 结论：可依法发包/流转，但须四议两公开 + 进产权交易平台 + 书面合同 + 10日内备案；同等条件本集体成员优先承包。依据：组织法、产权流转交易办法。
3. **多少钱要上会、要招投标？** → 跳阈值速查。
4. **合同最长能签几年？** 结论：土地经营权流转不得超过承包剩余期限；其它租赁参照本地制度与民法典，须书面、明确违约责任。配“以本县市最新制度为准”。
5. **白条能不能入账？** 结论：不能；“白条抵库”属违规，须取得合法正式票据。依据：财务制度。
6. **村务卡能刷多少 / 哪些不能刷？** 结论：日常零星支出可用，**严禁化整为零拆分**、严禁违规消费；大额走银农直联银行结算。

## F. 案例（case-learning，四段式：违纪事实 / 问题类型 / 处理结果 / 涉及条款）+ 正反对照
- **低价发包鱼塘给亲属**：口头决定、未公开未进场、显失公平 → 通报+追责+合同撤销。正确：方案→四议两公开→进场公开竞价→书面合同10日内备案。
- **白条抵库**：用白条/收据顶替正式发票入账 → 责令整改、追责。正确：取得合法票据、票据六有、七步签字。
- **坐收坐支**：现金收入不入账直接支出 → 违纪追责。正确：应收尽收、3日内存专户、票款分流。
- **私设小金库**：账外设账、公款私存 → 严肃处理。正确：统一资金专户、村账乡管。
- **超标准招待/发津补贴**：违规吃喝、滥发 → 退赔+处分。正确：非生产性开支限额、纳入预算、公开。
- 全国性数据可引用：吉林专项整治清查 49044 份合同、纠正显失公平 2684 份、挽回损失 1387 万余元。

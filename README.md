# 三资管理助手 · 前端原型

面向**村集体三资专干**的智能问答工具原型（纯前端、无后端）。围绕农村集体“三资”（资金、资产、资源）管理，把政策法规、业务流程、操作指南、典型案例整理成**可问、可查、可学**的助手。回答全部基于资料并标注引用来源，资料中没有的内容显示“未找到”兜底，从机制上**防幻觉**。

> ⚠️ 这是设计原型，内容为**示例数据**（引用了真实法规名称/条款/日期以保证可信度），不作为正式法律意见。

**布局自检状态：24/24 页通过（PC 12 + 移动 12），0 错误、0 警告**（由 `tools/verify-all.mjs` 经 Playwright 检测横向溢出/越界/裁剪/重叠/错位等冲突）。

## 一眼预览
```bash
npm run serve         # 启动本地预览：http://localhost:5173/
```
打开 **`/index.html`**（版本预览/决策页）：可实时切换 3 套配色、字号，并并排预览 PC 端与安卓端。也可直接双击任意 HTML 文件打开。

## 三套配色（可实时切换，供领导敲定）
- 🟢 **惠农绿**（默认）— 三农/亲和 + 政务蓝点缀 + 暖橙提醒
- 🔵 **政务蓝** — 权威、规范
- 🔴 **党政红** — 村务/政务公开气质

配色由 `shared/tokens.css` 的语义化 CSS 变量驱动（`html[data-theme="green|blue|red"]`）。任意页面可用 `?theme=blue` / `?font=large` 预览；选择会存入 localStorage 跨页生效。适老化“大字”模式整体放大一档。

## 目录结构
```
index.html              顶层版本预览/决策页（主题切换 + PC/手机实时预览 + 全部页面目录）
shared/
  tokens.css            设计令牌 + 三套主题 + 适老化字号
  components.css        组件库（按钮/卡片/对话气泡/引用标签/步骤卡/兜底卡/悬浮助手/底部Tab…）
  app.js                主题与字号持久化 + 轻交互（引用折叠/分段Tab/勾选/卡片翻转/助手开合）
pc/                     PC 端 12 个页面
mobile/                 安卓移动端 12 个页面
tools/
  verify-core.mjs       Playwright 布局检查核心（横向溢出/越界/裁剪/重叠/越界/小目标）
  verify-all.mjs        批量检查 + 截图 + 报告
  serve.mjs             极简静态预览服务器
  report/               检查报告与截图（git 忽略）
dev/                    设计契约、内容素材包、组件画廊、工作流脚本（非交付页面）
```

## 布局自检（Playwright 检查机制）
```bash
npm run verify                          # 检查 pc/ 与 mobile/ 全部页面
node tools/verify-all.mjs pc/qa-chat.html mobile/qa-chat.html   # 检查指定页
```
对每个页面在 PC(1440×900) 或 移动(390×844) 视口下渲染，检测：**页面横向溢出、元素超出视口、内容被裁剪(盖住)、静态文本块重叠(盖住)、元素跑出屏幕(错位)、移动端点击目标过小、缺 viewport、控制台报错**。每页输出两张截图：`*.viewport.png`（一屏所见，吸顶/吸底/悬浮位置真实）与 `*.png`（整页内容）。

## 定位与边界
助手是**解释器 + 导航器 + 合规顾问**：只“讲清楚、教明白、提示风险”，**不经手资金、不做录入/交易/审批**。一切真正办理动作以“去主系统办理”深链跳回三资主系统。可作为**全局悬浮插件**嵌入主系统业务页（见 `plugin-demo`）。

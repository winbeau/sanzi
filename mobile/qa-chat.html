招待餐费能不能直接报账？
资
不能 不能“直接”报

招待餐费是非生产性开支，不能随到随报。要先纳入预算、控制在限额内，确属公务，再按签字流程入账。严禁违规吃喝。

该怎么办
  1. 确认是公务接待、有真实事由；
  2. 金额在本村限额内、已纳入预算；
  3. 取得合法正式发票（不能白条顶替）；
  4. 走报销七步签字链入账。
系统里怎么点

本助手只讲清楚、不替你办。真正报账去主系统（银农直联）：上传凭证 → 一级审核 → 二级审核 → 银行付款。申请人和审核人不能同一人。

多少钱要上会、要招投标？
资
! 需注意 看金额档位

钱越多程序越严：小额理事会定，中额上代表大会，大额要四议两公开+招投标。具体数字各地不同，建议用「阈值速查」按金额一键判定。

该怎么办
  • 资产购建：≤5000 理事会+监事会；5000–5万 代表大会+备案；>5万 成员大会+公示。
  • 工程：<4万 成员大会；4万–100万 四议两公开+简易招标；>100万 按《招标投标法》。
金额是示例（中方县 2025），具体以本县市最新制度为准。

没发票，先打张白条入账行不行？
资
不能 白条不能入账

用白条、收据顶替发票入账叫“白条抵库”，是明确违规。必须取得合法正式票据才能记账，否则责令整改、追责。

该怎么办
  1. 先补开正式发票，写清事由用途；
  2. 按票据“六有”自检齐全；
  3. 再走七步签字链入账；拿不到票咨询代理中心。
